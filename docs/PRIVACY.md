# 发布隐私边界

此仓库由独立白名单目录生成，不是工作目录的整目录提交。

公开范围：源码固定提交、四个有效补丁、新编写的构建工具与说明、软件输入文件路径/哈希、脱敏验证结果；Releases 为原始完整 OTA、同版本启动/恢复镜像、对应源码快照和校验和。

排除：设备序列号、IMEI/MAC、私人局域网拓扑/地址、SSH认证材料、令牌/密码、Wi-Fi配置、用户/NV/校准/原厂回读备份、Android或Ubuntu用户目录、密钥环、Codex/Google账户登录和聊天记录、截图、原始运行日志、Magisk启动镜像、GApps、个人 APK 签名私钥。

固件来自已校验的构建输出，非平板系统回读。OTA 的十二个软件分区不包括 userdata、persist、NV、GPT 或 ABL。它仍包含正常运行系统所需的原厂专有组件，其权利归各权利人；并非将这些组件宣称为开源。

源代码快照只来自固定 Git 树及审核的改动；上游公开源码中的版权作者名、测试夹具、公开证书等不等于用户个人数据。未将构建机 .git 配置、凭据或未跟踪文件带入快照。
