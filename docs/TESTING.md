# 验证范围与限制

固件构建日期 2026-10-14，发布整理日期 2026-10-16。

## 已完成的历史实测

- 单台 TB320FC PRC：原生 Recovery 安装、标准 A/B OTA、保留数据更新和普通重启。
- 用户验证 Wi-Fi 上网、前后相机、扬声器、旋转、双击亮屏正常；非覆盖所有场景的自动化测试。
- SELinux Enforcing；构建 VINTF、依赖与 ELF 检查通过；711 个已打包模块 vermagic 匹配。
- Android 和独立 Linux 用户空间共用此内核，普通用户原生桌面应用沙箱、终端 PTY、SSH 实测通过。
- Health API / 设置 UI 返回有效原生 SOH。没有修改 NV、校准数据或人为填入最大容量。

## 离线验收

原始 OTA CRC、payload 分区哈希和容量、OTA/payload 签名及 AVB 镜像签名验证通过。2026-10-16 再次对原始固件和六个镜像计算 SHA256，均匹配上述已验证构建。

## 已知限制 / 未验证

- 上游 userdebug、test keys、AVB flags3；不能宣称 AVB 强制校验或生产级安全。
- 上游 ROW 指纹保留；PRC 有 ABL 区域/版本检查，启动器不匹配曾出现红色不兼容提示。
- 测试设备使用已独立验证的、签名有效且版本一致的 PRC ABL；没有跨区域刷写通用解锁包。本项目不提供 ABL/EDL 写入工具或镜像。
- 实际物理 super 为 12GiB；上游镜像布局约 6GiB，保留其动态组，不做 GPT 重分区。其他布局未验证。
- 没有覆盖 NEC、其他 Y700 年款、全量蓝牙配件、DRM/Widevine、Play Integrity、银行应用、长期续航/待机和所有 USB 外设。
- 单台正常使用反馈不能证明所有硬件长期稳定。电芯真实满充容量未测量。
- 自定义 Linux 桌面、启动器、Magisk 和 GApps 是后续独立部署，不包含在 OTA 中。
