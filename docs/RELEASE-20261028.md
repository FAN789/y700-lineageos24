# LineageOS 24 · Y700 TB320FC · 20261028 / 1793184607

非官方 Android 17 构建，仅一台 TB320FC PRC 实机完成本次验收，不代表其他年款、区域或批次兼容。

## 改动与验收

- 修复 USB 控制器初始化与 Type-C 3.0A 伙伴状态识别。
- Recovery 只读加载当前槽原厂固件并自动初始化 ADSP，使两个 USB-C 口的冷启动维护和 sideload 通道可用；两个口均在原扩展坞链路实测通过。
- 保留电池健康显示、Codec2 和 A/B 更新保留修复。核心内核及 711 个模块相较上一候选未变。
- 整包 CRC、payload 哈希/签名、12 分区容量/哈希、AVB、VINTF、SELinux 及签名连续性通过。标准 A/B 保留数据更新、已有 GApps/root 保留、正常重启与硬件视频编解码通过。
- Wi-Fi、相机、声音、旋转、双击亮屏此前已由用户验收；本次没有重复宣称新的人工感官全量测试。保留原有 Recovery vendor_init 只读告警，本次未增加相关权限。

本包采用本项目专用发布签名，129 个 APK 和 37 个 APEX 身份与已迁移的专用签名渠道连续。**旧公开 test-key 版本和原厂系统不能直接按保留数据 OTA 覆盖本包。** 首次迁移需另行制定受验证的签名/数据迁移或干净安装方案；本 Release 不提供通用解锁、ABL 或 EDL 写入命令。已在相同专用签名渠道的兼容设备可使用标准 A/B OTA；安装前保留本人恢复备份，不重分区，不盲切旧槽或强制降级。

这是 userdebug、Bootloader 解锁、继承 AVB flags 3 的非官方系统；专用签名不意味着锁定 Verified Boot，不要重新锁 BL。OTA 是未加 Magisk 的原生签名产物，不内置 GApps、个人 Linux 环境、账号或设备备份；已有组件的保留以适用的保留脚本和实机验证为前提。
